# KinLink Family Tree App Flow Document

## Onboarding and Sign-In/Sign-Up
A new user discovers the KinLink app through an app store listing or a shared download link. When the user opens the app for the first time, they land on a welcome screen that briefly explains the purpose of the family tree application and invites them to sign up or log in. The user can choose to register with their email and password or connect with a social provider such as Google or GitHub. In the email registration flow, the user enters their name, email address, and a secure password, then taps "Sign Up." A verification email is sent automatically. Once the user clicks the verification link in their email, they return to the app, which confirms the account and directs them to set up their profile. If the user already has an account, they tap "Sign In," enter their credentials, and gain access to the main application. Should the user forget their password, they can tap "Forgot Password," provide their email, and receive a reset link. Following the link allows them to choose a new password and return to the sign-in screen. The app also offers a "Remember Me" option to keep the user signed in across sessions. Signing out is available from the settings screen, and it immediately returns the user to the welcome page.

## Main Dashboard or Home Page
After signing in, the user arrives on the Home screen of KinLink, which serves as the central hub. At the top, a header displays the app logo, a menu button, and a notification icon. The bottom of the screen features a tab bar with four main sections labeled Home, Tree, Activity, and Profile. The Home tab shows a snapshot of recent activity across all family trees the user is part of, along with a button to quickly start a new tree or open an existing one. Tapping the Tree tab navigates the user to a full-screen interactive family tree viewer, where they can pan, zoom, and select individual members. The Activity tab lists a chronological feed of changes made by all collaborators, and the Profile tab reveals the user’s personal settings and account details. The sidebar menu, accessible from the header button, slides in from the left and offers quick links to support, app settings, or logout. From this main dashboard, the user can move seamlessly to any feature by tapping the corresponding tab or menu item.

## Detailed Feature Flows and Page Transitions
When the user taps the Tree tab, they see their list of family trees. Selecting an existing tree opens an editor screen that displays a graphical chart of members connected by relationship lines. The user can tap any member node to open a detail panel where they can view or edit the member’s information. To add a new person, the user taps the floating action button in the corner. This action opens the Add Member screen, which presents a form managed by React Hook Form and validated by Zod. The user fills out fields such as name, date of birth, and relationship role, and can upload a profile photo. Once the user taps "Save," a transaction runs in the background using Drizzle ORM. If the transaction succeeds, the new member appears in the tree with an animated insertion. If it fails, an error message informs the user and the form remains open for correction. To edit an existing profile, the user selects a member node, taps "Edit," updates details in a similar form, and saves. Photo changes are handled by uploading the file to Supabase Storage. The app subscribes to real-time updates for the active tree, so if another collaborator makes a change, the tree automatically refreshes with a smooth transition. The Activity tab shows detailed logs in a chronological list, and tapping any entry highlights the affected member in the Tree view. Users can switch between trees by opening the sidebar menu or by tapping a list item on the Tree tab. Throughout the experience, navigation transitions are driven by React Navigation stacks, ensuring the back button returns the user to the previous screen in a natural way.

## Settings and Account Management
In the Profile tab, the user sees their avatar, display name, and email address. They can tap "Edit Profile" to change their avatar by selecting a new photo or to update their display name. The user can also manage notification preferences by toggling real-time activity alerts on or off. The app provides a switch to toggle between light and dark themes inspired by nature’s color palette. To change an email or password, the user taps "Account Settings," which prompts them to confirm their current password before entering new credentials. Any updates are saved in Supabase Auth and reflected immediately in the app. If the user has multiple connected social logins, they see an option to unlink or link additional providers. From the same screen, the user can review their subscription status if a premium plan exists, upgrading or canceling within a secure billing portal that loads in an in-app browser. After making changes in settings, the user taps "Save" to commit updates and returns automatically to the Profile overview. A "Back" arrow in the header always brings the user back to the main dashboard.

## Error States and Alternate Paths
If the user enters wrong credentials on sign-in, the app displays a red error message beneath the form fields prompting them to retry or reset their password. During data entry on the Add Member or Edit Member forms, invalid fields are highlighted with inline messages explaining the required format. If the device loses internet connectivity, the app shows a persistent banner at the top stating "Offline Mode" and gracefully queues write operations in local storage until the connection is restored. In the event a database transaction fails server-side, a toast message appears at the bottom with a short description and a "Retry" option. If a real-time subscription drops unexpectedly, the app attempts to reconnect in the background and notifies the user with a subtle status indicator in the header. Attempting to access a restricted resource, such as a private tree the user is not invited to, redirects to an error page that explains access is denied and provides a button to return to the Home tab. All error and fallback states include clear guidance for regaining a normal workflow.

## Conclusion and Overall App Journey
From the first tap on the welcome screen through daily collaboration on a shared family tree, KinLink guides users with clear screens and smooth transitions. The journey begins with account creation or login, moves into an activity-rich dashboard, and flows seamlessly into building and exploring family trees with real-time updates. Users can manage their profile and preferences anytime, confident that errors are handled gracefully and their data remains consistent. Each screen connects logically to the next, ensuring that adding a grandparent, reviewing a cousin’s update, or switching to dark mode feels natural. By the time users complete their first tree and invite relatives, they have experienced every key page and feature, setting the foundation for ongoing discovery and storytelling within their family history.
